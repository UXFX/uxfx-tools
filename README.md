# uxfx-tools

Plugins for Claude by Dale Jones (UXFX). Each one does real work and teaches the thinking behind it.

**New here? Start with the [Getting Started guide](GETTING-STARTED.md)** — it takes you from nothing installed to running plugins, no technical background needed.

| Plugin | What it does |
|--------|--------------|
| **Premise** | Thinking partner for work you've been handed or taken on. Separates what you know from what you're assuming, then produces a Launch Brief — understanding plus a plan. |
| **Context engineering training** | A 9-session, hands-on program that teaches context engineering for Claude Desktop and Cowork. You build a real workflow from first principles to a productionized system. |
