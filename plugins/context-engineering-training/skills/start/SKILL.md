# Start Training

Welcome a new student and set up their training workspace.

## Process

### Step 1: Welcome and Orient

Introduce yourself. Keep it brief — no more than 3 paragraphs:

- This is a hands-on training program for Claude Desktop and Cowork
- You'll build a real workflow across 10 sessions — not toy exercises
- The training itself is a plugin running inside Claude, so you're already learning by doing

Then ask: **What's your name?**

🛑 **CHECKPOINT** — Wait for the student's name.

### Step 2: Check Environment

Verify the student has what they need:

1. Are they running Claude Desktop? (They must be, since they're running this plugin — confirm it.)
2. Are they on a paid plan? Cowork works on Pro, Max, Team, and Enterprise. (Ask them to check.)
3. Can they see the Cowork tab?

If anything is missing, help them get set up before continuing.

🛑 **CHECKPOINT** — Confirm environment is ready.

### Step 3: Initialize Workspace

Create the training workspace:

1. **Read templates/** and deploy to the student's workspace folder:
   - `STATE.md` — Set student name and start date
   - `WORKFLOW.md` — Leave blank (filled in Session 2)
   - `learning-journal.md` — Deploy empty (appended to after each session)

2. **Update STATE.md:**
   - Set Student Name
   - Set Started date (today)
   - Set Session 0 status to "In Progress"

3. **Set Position:**
   - Session: 0
   - Tier: Foundation

### Step 4: Generate Initial Portal

Invoke the `portal` skill to generate `training-portal.html` in the student's workspace. This is their progress dashboard — it updates after every session. Present it to the student as a file link so they can open it.

### Step 5: Hand Off to Session 0

Tell the student:
- Their training workspace is set up
- Session 0 is orientation and configuration — you'll see what you're building toward and get Claude dialed in
- The real hands-on learning starts in Session 1

Then invoke the `session-0` skill.
